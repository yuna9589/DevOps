# Week 05: CI/CD 파이프라인과 자동화 기초

## 1. 학습 목표
- 지속적 통합(CI) 및 지속적 배포(CD) 개념 이해
- GitHub Actions를 이용한 자동화 워크플로우 구축
- 코드 변경 시 자동으로 빌드/테스트가 실행되는 과정 확인

## 2. 주요 실습 내용
- GitHub Actions 워크플로우 정의:
  - .github/workflows/ 내 YAML 워크플로우 파일 생성
  - 트리거 이벤트(push, pull_request) 및 Job, Step 정의
- 자동화 실습:
  - 체크아웃 액션(actions/checkout)을 통한 소스코드 다운로드
  - 빌드 및 기본 테스트 자동화 실행

## 3. 트러블슈팅 및 배운 점
- 코드 수정 및 푸시만으로 빌드/검증이 자동으로 수행되어 개발 생산성과 안정성이 크게 향상됨을 이해함.
